## 最终任务

**任务：密码重置 token 过期拒绝并记录审计事件**

可观察结果：过期 token 不能完成密码重置、密码状态保持不变，并产生可归因的拒绝审计事件；未过期 token 的既有成功路径不回归。

### task 内部 TDD 步骤

1. RED：在现有密码重置测试套件和共享 fixture 中加入过期 token 场景，断言请求被拒绝、密码不变且产生预期审计事件；运行项目原生聚焦测试，确认失败源于过期判断和审计行为尚未完整实现。
2. GREEN：在同一模块实现最小 token 过期判断及该拒绝路径所需的审计事件，使新增场景通过。
3. REFACTOR：只整理当前行为必要的重复设置或命名；若发生代码变更，复跑同一聚焦测试。

### 验收项与证据

- 过期 token 返回规格约定的拒绝结果，且不写入新密码；
- 审计事件类型、原因、主体和关联标识符合现有审计契约；
- 未过期 token 的密码重置路径继续通过；
- 聚焦证据：从仓库现有 package script/test 配置读取并实际运行密码重置模块的原生聚焦命令，记录命令、退出状态和关键结果，不臆造 runner；
- 组级证据：运行覆盖“过期拒绝 + 状态不变 + 审计事件”的完整项目原生场景验证，并把结果归属于此任务。
