## 最终任务

**任务：实现密码重置 token 过期拒绝与审计闭环**

任务结果：过期 token 被拒绝且不改变密码，并记录符合现有契约的审计事件；正常 token 路径保持通过。

### task 内部 TDD 与验收项

1. RED：使用现有共享 fixture 添加过期 token 的失败测试，覆盖拒绝结果、密码不变和审计事件；运行仓库已有的密码重置聚焦测试，确认目标行为缺失导致失败。
2. GREEN：实现最小过期判断和拒绝审计行为，循环运行新增及直接受影响测试直至通过。
3. REFACTOR：只做完成当前任务所需整理，并复跑相同测试。
4. 验收：过期拒绝、密码状态不变、审计字段正确和未过期路径回归全部有真实测试证据。

验证时先从项目现有 package scripts 或 test 配置读取原生命令：运行密码重置模块聚焦测试，并运行覆盖过期拒绝与审计闭环的完整场景测试；记录实际命令、退出状态和关键结果，不假设通用 runner。

本规划不按测试文件、实现函数或执行 worker 分割完成状态；RED、最小实现、审计断言和必要 REFACTOR 都留在该行为任务内部。旧版对此决定的直接依据是“可独立验收”与“任务本地 TDD”，而不是 v4.2 新增的显式任务粒度门禁。
