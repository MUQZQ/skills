# 独立工具域

## 职责

本 Skill 只负责将明确的专业工具意图路由到叶子 Skill。权威映射位于
`references/tool-mapping.yaml`。

## 整体任务交接

遵循根 `AGENTS.md` 的“方法论驱动的整体运行”及共同交接约定。本域接收当前方法阶段需要的专业产物与验收条件，返回实际结果、证据和未决项；主 Agent 据此继续原方法阶段。领域完成不等于任务完成，不重启整体规划或另建任务账本。本域的主 Skill 指当前职责的执行能力，与任务推进方法职责互补时可以同时保留。

## 路由规则

1. 用户显式指定子 Skill 时直接执行。
2. 每次只选择一个主工具；混合请求由当前主 Agent 保留整体目标、授权和验收，按阶段交接产物。只有软件实施或 Git 交付阶段进入 `orchestration` 已注册入口，非编码任务不转为编码流程。
3. 从映射取得规范 `skill_name`，再通过根注册表解析 `<skill>/SKILL.md`；专业约束以叶子 Skill 为准。
4. 未匹配的工具需求返回缺口，不在本域临时扩展无权威定义的流程。
