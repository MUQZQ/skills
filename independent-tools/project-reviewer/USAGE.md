# 使用说明与统计

## 使用方法

1. 在目标项目里对 AI 说："用 project-reviewer 技能给这个项目建 review 工程"，附上基准物位置（设计图/规格/契约文档）。
2. AI 按六阶段产出 `review_<project>/` 工程；阶段 0 映射表与就绪谓词通过后即可逐项执行。
3. 执行角色：评审会话逐项跑检查、填证据、出轮次草稿；用户只处理 4 个人工节点（BLOCKED 确认 / NA 与再基线确认 / 主观接受 / 止损升级）。
4. 实现方会话对本工程的 tracks/ 与 evidence/ 只读禁写。
