# 使用说明

保留完整的 `release-test-report` 文件夹。将文件夹放到目标客户端支持的 Skill 目录，或直接打开 `SKILL.md` 按流程操作。使用 Excel 或 WPS 编辑工作簿，直接复制 `assets/发布测试报告模板.xlsx` 即可开始。以下脚本从 Skill 根目录运行。

## 创建和检查 Excel

`scripts/workbook.py` 使用 Python 3.9+ 标准库。它从包内复制模板，检查六张表、冻结、筛选、状态下拉、公式和用例编号、主测人、结果等填报字段。

```powershell
python scripts/workbook.py new ./发布测试报告.xlsx
python scripts/workbook.py check ./发布测试报告.xlsx
python scripts/workbook.py check ./assets/发布测试报告模板.xlsx --template
```

`new` 保留已有同名文件。检查通过表示结构和填报字段符合检查规则。正式包来源、截图与场景对应、覆盖范围和最终验收结论按 `SKILL.md` 核对。新增表格行时确保 Excel 将它纳入对应的原生数据表，并扩展状态下拉、条件格式和链接。

## 获取 PR Helper 证据

`scripts/prhelp_evidence.py` 使用 Python 3.9+ 标准库。用当前项目的授权凭据在运行环境中设置 `PRHELP_API_KEY`。通过 `PRHELP_SERVER` 或 `--server` 提供该服务的站点根地址，可带端口。应用路径默认 `/serve/patodo/pr-help`，服务部署不同可用 `--app-path` 指定。先列出轮次，根据场景选择后再下载正文和原图。

```powershell
$env:PRHELP_SERVER = 'https://prhelp.example.com'
python scripts/prhelp_evidence.py reviews --pr 123
python scripts/prhelp_evidence.py collect --pr 123 --round 456 --out ./取证 --images
```

每轮输出到 `pr-123-round-456/`，包括 `review.md`、`manifest.json`，指定 `--images` 时另有 `images/`。清单记录 PR、评审轮次、提交、时间、评审链接及原图来源。取证内容是工作材料，确认与当前发布功能对应后再写入报告。HTTP 401 或 403 应按权限问题处理，可改用已有授权评审记录并注明缺口。截图仅取自同服务的评审所引用的原图。

## 重建空白模板

包内已包含可用的 Excel 模板。维护模板时可在提供 `@oai/artifact-tool` 的 Node.js 环境中运行同包脚本。脚本生成空模板和两张预览图。

```powershell
node scripts/build_template.mjs ./模板输出 --test
node scripts/build_template.mjs ./模板输出
```

将新模板替换到 `assets/` 前，先运行工作簿检查，并对照摘要、冻结区域和截图栏布局。
