# 产品介绍片策划指南

适用于面向潜在用户或客户、需要突出产品价值与核心功能的介绍片。本文定义策划与证据约束；实际制作按 [计划格式](workflow.md) 调用脚本。脚本支持多素材、字幕、静态裁剪和高亮框；动态跟踪、复杂动效与营销效果评估不在本次能力范围。

本文的策划流程和输出模板只用于产品介绍片。若用户明确要求保留完整教程或原有操作顺序，返回主 Skill 的教程流程；即使已加载本文，也不要要求价值主张、营销 CTA 或重排教学步骤。

## 策划流程

1. **确定观众与任务**：从上下文提取受众、观看场景、已知问题和希望的下一步。缺少关键事实时列为待确认，不猜测。
2. **写一句价值主张**：用观众能理解的语言说明产品帮助谁完成什么、带来什么价值。避免空泛形容词、未经证实的量化承诺和产品内部术语堆叠。
3. **列出卖点与证据**：每个卖点对应可核实的依据和实际素材镜头。说明证据来自用户提供的录屏、截图、产品文档或用户确认；区分事实、推断与待核实项。没有证据的功能/效果不写成已实现事实。
4. **组织叙事**：按“痛点 → 价值 → 2–3 个演示点 → 结果 → 单一 CTA”规划。演示点是建议结构而非硬上限；用户必须涵盖更多主题时完整纳入，并说明信息密度及可读性取舍。不要强行套固定片长、配音、平台比例或节奏。
5. **映射镜头与文字**：逐镜写清叙事作用、对应卖点、源素材/时间位置、观众应注意的真实界面区域、屏幕文字或旁白意图及预计阅读停留。重点内容应可读；高分辨率真实 UI 优先，按信息重点裁剪，避免模糊放大和遮挡关键界面。
6. **检查真实性与品牌素材**：仅使用用户提供或明确授权的产品界面、商标、字体、图片、视频和数据。缺少画面时标注缺口并提出补录/补充素材需求，不伪造 UI 或结果；不得把示意图伪装为真实产品。品牌素材来源要可追溯。
7. **检查静音理解与分流**：关键信息应能在静音观看时理解，可用简洁屏幕文字承载核心信息，使用正式文稿生成字幕时，先核对字幕与画面锚点，不能把合成用的谐音稿直接上屏。把完整操作教学留给教程；介绍片只保留支撑价值理解的操作，除非用户要求全面覆盖。
8. **标明制作边界**：静态裁剪、高亮框、文字字幕可直接制作；平滑跟踪、动态缩放、品牌动画和复杂动效需要额外工具，不能冒充已支持。不要承诺营销转化提升；可提出后续用目标观众理解度观察验证。

## 镜头选择与节奏

- **问题镜头**：呈现观众实际面对的任务，用一句简短文字交代困难，避免长片头。
- **核心演示**：每个段落聚焦一个结果。先给必要操作上下文，再放大目标区域，保留足够的结果阅读时间；等待可剪掉，但不可让剪辑伪造响应速度或成功率。
- **前后对比**：只有同条件、可核实的素材才做效果对比；没有对照证据时展示流程变化，不编造性能数字。
- **结果镜头**：保留真实输出、来源或可追溯信息，让观众看到价值如何发生。不要用宣传大字遮住关键参数和引用。
- **结尾镜头**：停留在真实结果页或已有品牌素材上，给一个明确下一步。没有链接或联系方式时标注待补，不编造地址。

使用同一套字幕字体、强调色、措辞和配音。先做一段最难读的试片，在预期观看尺寸下核对；竖屏需重新构图，不能把横屏界面直接挤窄。配乐不是必需项：使用时核对授权并压低至不掩盖人声；当前脚本不混合背景音乐，不暗示已经处理。

## 成片检查

1. 静音观看：能否看出产品解决的问题、主要结果和下一步；字幕是否遮住操作或小字。
2. 有声观看：旁白所指与画面是否同时出现，术语是否正确，等待压缩是否误导。
3. 缩小观看：结果表格、关键点击和高亮是否仍可读；模糊素材用原片替换，不靠字幕掩盖。
4. 对照事实：逐项回看卖点证据，注明实机画面、示意画面与尚待验证的主张。
5. 技术检查：实际总时长、解码、音轨能量、字幕边界和交付目录均通过。以上检查不能证明转化率提升，目标观众理解度需要另做观察。

## 从镜头卡到成片验收

不要直接从一两张截图挑选方便渲染的区间。先沿素材找到完整的输入、动作、状态变化与结果，核对实际源时间，再按价值挑选。用当前策划表或计划旁的简短说明记录以下镜头卡，不另外创建任务账本：

| 内容 | 要回答的问题 |
|---|---|
| 作用与证据 | 支撑哪个卖点？是操作前状态、操作过程、结果还是补充说明？结果是否真的出现？ |
| 源区间与锚点 | 哪份素材、哪段时间；动作/结果分别发生在哪一刻？未查看时写待核对，不编时间。 |
| 观众注意点 | 具体哪个字段、按钮或结果应被看见？裁剪后是否仍保留产品与任务上下文？ |
| 时长理由 | 配音实际多长，动作需要多长，观众要读什么？不能只为了填满时长。 |
| 构图与标注 | 在目标观看尺寸能否看清？高亮覆盖哪些内容，何时出现/消失？ |

未合成配音时，每镜分别列画面总时长、旁白估算时长、动作与结果阅读预算，并说明哪些时间并行、哪些依次发生；不能把整镜时长直接当成旁白时长。按实际文稿估算，不猜字数；估算只用于排期。合成后测实际语音，重新核对段长与总长；过长先改稿或调镜头，不能把估算当作可用的实际时长。

先做代表性短样，再扩展：短样须包含一个核心价值结果、一处难读区域和相邻镜头的切换，而不只是验证编码、字体或配音是否可用。没有结果素材时可做技术样片或分镜草稿，但必须保留“待补素材/未完成成片验收”。

### 针对实际问题的处理

- **选段**：模型“未选择”、空表单、加载进度可交代准备过程；宣传价值要由真实输出、查询命中、来源依据或完成状态承载。不能通过改旁白把处理中包装成已完成。
- **节奏**：默认先删除无信息增量的停留，再压缩等待。慢放用于难辨动作时保留动作上下文；静态结果阅读可停留，避免用无意义慢放制造长度。
- **声音与字幕**：测量合成后语音的实际起止，检查句间和片尾留白。长静音先判断是否用于读表、对比或行动指引；无内容承载才缩短。字幕要覆盖对应语义，按阅读需要停留，不能只凭音频长度或机械字数判断。
- **构图**：优先让主信息占据画布；多素材之间保持接近的文字视觉大小。留边可承载字幕/品牌或维持必要上下文，不能为消除黑边拉伸界面或裁掉核心字段。先在预期观看尺寸看图，避免只看放大的编辑器预览。
- **高亮**：框住具体目标，并尽量限于需要引导的时段；当前脚本整段显示框，需短时标注时拆段。整行表格是必要目标时允许宽框；避免框住大半页面仍无法说明注意点。
- **切换与收尾**：在切点前后检查状态衔接、字幕有无跳闪、声音是否中断；结果阅读完成后给清晰的产品识别和单一下一步。局部技术片段无需硬塞完整片头/CTA，但不能按完整介绍片交付。

### 验收结论

交付时分别写“技术：通过/失败；成片审看：通过/待修订/未完成”，列出有时间点的证据与尚未完成的项目。无试听能力时，声音自然度/术语发音仍是未完成；音轨非静音或自动转写不能代替试听。文件可解码、测试全绿与漂亮的策划稿均不能代替实际成片检查。

自动诊断的阈值只是待复核信号。必要阅读停留、授权静音版、窄表格或竖屏素材留边可以合理保留；逐项解释即可，不为清除提示而破坏表达，也不强迫每个视频符合固定时长、平台比例或动作密度。

## 输出结构

- **受众与观看任务**：已知信息和待确认项。
- **一句价值主张**：一句话。
- **卖点—依据—镜头映射**：逐项列出主张、证据来源/状态、素材与时间位置、镜头意图、需要补充的素材。
- **分镜顺序**：痛点、价值、演示、结果、CTA；说明必要主题覆盖与时长/可读性取舍。
- **真实性、品牌与静音检查**：需要核对的素材权属、真实 UI、屏幕文字可读性和无声理解情况。
- **制作边界与待办**：区分现有录屏处理能力、静态策划建议、需要额外工具/素材的部分。
