# 小说原创选题

## 使命与边界

把模糊的创作愿望转成可验证的原创选题。只参考平台节奏、读者情绪需求和媒介约束，不复制任何
作品的独特设定、人物组合、名场面、标志性台词、章节链或终局结构。

本 Skill 不写正文，不替用户改写现成作品，不默认创建项目文件，也不承诺“绝对原创”或“必然爆款”。
公开检索只能降低已发现的相似风险；正式发布前仍需作者人工复核。

## 输入

先从对话提取以下条件，已有答案不得重复询问：

- 目标平台和媒介：免费阅读、付费阅读、短视频、真人微短剧、AI 漫剧等；
- 篇幅和完结方式：章节数、字数、单季闭环或可续季；
- 类型与目标读者：男频、女频或不限，都市、悬疑、幻想等；
- 期待爽点：反杀、打脸、智斗、身份翻转、关系反转、资源逆转等；
- 禁区：不接受的题材、结局、尺度和高频套路；
- 制作约束：场景、角色、特效、拍摄或生成成本。

缺失信息不会显著改变结果时，用“暂定假设”继续；会改变整个候选池时，只问一个关键问题。

## 铁律速查

| 规则 | 内容 | 违反后果 |
|------|------|---------|
| R0 | 只参考市场机制，不复制具体作品表达 | 选题沦为换皮或擦边模仿 |
| R1 | 当前趋势必须联网核验，并区分事实、推断、假设 | 把过时印象当成平台事实 |
| R2 | 先产生10—15个不同故事发动机，再开始评价 | 被第一个点子锚定 |
| R3 | 候选必须完成同名、机制、关系、终局四层扫描 | 只查书名却漏掉实质撞题 |
| R4 | 两层以上达到中高风险的候选不得进入前三 | 用换名掩盖结构相似 |
| R5 | 反转必须改变信息、关系、目标或资源 | 只揭秘密，剧情没有推进 |
| R6 | 不承诺绝对原创、全网唯一或市场成功 | 对检索覆盖和市场结果作虚假保证 |
| R7 | 本 Skill 到选题实验为止，不写正文、不擅自立项 | 越过用户授权与写作生命周期 |

## 工作流

### 1. 建立探索边界

输出目标、已知约束、暂定假设、明确不做和3—5个关键未知。把“适合当前平台”拆成可观察指标，
例如首章承诺、每3—5章情绪回报、30—60秒可视冲突、制作成本和完结闭环。

### 2. 联网核验公开信号

至少覆盖三类来源：目标平台官方榜单或征文、近一年行业或机构报告、同类作品与反例。优先一手
来源，记录标题、链接、日期和适用范围。每条结论标注：

- **事实**：来源直接支持；
- **推断**：由多个事实推导，并写明推理；
- **假设**：需要样章、读者或投放数据验证。

榜单样本不能单独证明长期趋势；无法联网时写明“未核验”，停止作当前趋势断言。

### 3. 结构化头脑风暴

先发散10—15个候选，不评分。候选至少覆盖四种镜头，每种2—3个：

- 直接路径：用成熟类型承载一个新发动机；
- 消除或反转：移除系统、重生、万能能力等默认部件；
- 相邻类比：从真实职业、流程、空间或技术迁移冲突；
- 约束变化：压缩到30章、少场景、少角色或低特效；
- 媒介原生：让镜头、直播、评论、证据或现场动作参与叙事，但不照搬已有作品。

每个候选写：暂定题名、一句话故事、故事发动机、爽点循环、反转来源、短视频画面、篇幅闭环、
最大原创风险。不能只更换职业名称来制造“不同候选”。

### 4. 四层相似风险扫描

逐个搜索并记录检索词、近似作品、相似点和差异点：

1. **同名**：完全同名、近似标题、标题关键词加类型；
2. **核心机制**：能力、规则、触发事件、爽点循环、固定场景和关键道具；
3. **人物关系**：主角与反派、亲属、恋人、搭档之间的秘密与翻转路径；
4. **终局反转**：主角身份、组织目的、世界真相和最终胜负方式。

风险只写“公开检索未发现、低、中、高或无法判断”。共享普通母题可以保留；共享核心机制需要
重做；人物关系和终局也接近时直接淘汰。换名字、换城市、换性别不算原创修复。

### 5. 主动淘汰并收敛

列出被淘汰候选及具体原因。只保留三个差异明显的角色：稳妥路径、进取路径、最高学习价值路径。
统一比较追读钩子、爽点密度、反转质量、短视频适配、制作成本、篇幅闭环、原创风险和续季弹性。
不给没有依据的精确分数。

### 6. 设计最小验证实验

对首选只设计实验，不写完整章节：

- 第1章：异常事件与核心承诺；
- 第2章：主角主动行动，展示独特解法；
- 第3章：第一次反转、实际代价和更大问题；
- 1—3条短视频切片：0—3秒钩子、3—15秒错误认知、15—40秒行动与翻转、40—60秒结果和悬念；
- 通过条件：陌生读者能复述规则、愿意追下一章、能说出与近似作品的实质差异；
- 否决条件：必须依赖长篇解释、反转无伏笔、或被稳定识别为某部作品的换皮。

## 输出

按以下顺序交付：

1. 需求边界与暂定假设；
2. 联网证据摘要，区分事实、推断和假设；
3. 10—15个发散候选；
4. 四层相似风险扫描；
5. 主动淘汰清单；
6. 三个收敛候选及推荐顺序；
7. 首选的前三章与短视频实验；
8. 未核验事项和原创风险声明。

## 实战反例

| Agent 可能产生的想法 | 实际现实 | 违反规则 | 后果 |
|---------------------|---------|:------:|------|
| “没有同名书，所以设定安全” | 标题不同也可能共享故事发动机和终局 | R3 | 漏判实质撞题 |
| “换掉店名和主角名就原创了” | 表达外壳变化不能消除结构相似 | R0、R4 | 产出换皮方案 |
| “平台喜欢系统文，直接再做一个系统” | 趋势不等于复制许可证 | R1、R2 | 同质化且缺少辨识度 |
| “短视频就是每章留悬念” | 没有可视动作与局部回报，切片仍不可用 | R5 | 只有预告，没有爽点 |
| “搜索没结果就写全网首创” | 搜索引擎和平台索引都可能遗漏 | R6 | 误导用户 |
| “题已选好，顺便写前三章” | 探索不自动授权正文创作 | R7 | 越权写作 |

## 错误处理

| 情况 | 处理 |
|------|------|
| 网络不可用 | 标记未核验清单，只做暂定发散，不给趋势结论 |
| 候选全部高风险 | 回到故事发动机重新发散，不机械换名 |
| 只有聚合或百科结果 | 降低置信度，继续寻找平台原页或权威来源 |
| 用户要求模仿具体作品 | 提炼高层节奏特征，拒绝复制独特表达和桥段 |
| 用户要求开始写作 | 转交项目自己的写作生命周期 Skill |
