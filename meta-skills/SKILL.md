# 元技能域

## 职责

本 Skill 只负责识别元技能意图并路由，不复制叶子 Skill 的执行流程。权威映射位于
`references/meta-skill-mapping.yaml`。

## 整体任务交接

遵循根 `AGENTS.md` 的“方法论驱动的整体运行”及共同交接约定。本域接收当前方法阶段需要的专业产物与验收条件，返回实际结果、证据和未决项；主 Agent 据此继续原方法阶段。领域完成不等于任务完成，不重启整体规划或另建任务账本。本域的主 Skill 指当前职责的执行能力，与任务推进方法职责互补时可以同时保留。

## 路由规则

1. 用户显式指定子 Skill 时直接执行。
2. 每个阶段只选择一个主 Skill；混合请求按当前所需产物选择，并保留整体交付目标。
3. 从映射取得规范 `skill_name`，再通过根注册表解析 `<skill>/SKILL.md` 并严格执行其步骤。
4. 无法匹配时说明缺口，不在元技能域内发明新的专业工具流程。
