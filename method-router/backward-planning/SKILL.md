# 逆向规划

## 输入

提供目标状态描述、现状证据和约束（时间/资源/依赖）。目标还写不出可验收判据时先转交 SMART 校验。

## 执行

1. 把目标改写为可验收的终态判据（交付物 + 证据）；写不出判据就先退回 SMART。
2. 从终态倒推：达成终态的前一步是什么？逐个向前追问，直到落到现状。
3. 每个里程碑标注可观测证据、前置依赖和最短验证方式。
4. 与正向计划对照，列出倒推暴露的遗漏步骤与顺序冲突。

## 输出

输出里程碑链：终态 ← M3 ← M2 ← M1 ← 现状，每步带验收判据、依赖与证据方式；
并单独列出倒推发现的遗漏清单与顺序冲突。

## 边界

本 Skill 只做终态倒推与路径生成：目标体系未建立时先转交 OKR/SMART；需要排序失败风险时转交
pre-mortem；完全初始、连目标都没有的任务转交 discovery-sprint。它不排期、不分配资源；
里程碑冲突只标记并交回主 Agent 决策。
