# 检查清单与耐心等待

## 输入

提供决策门槛、尚缺证据、复核责任人、日期和可接受损失。需要时读取 `../references/munger-source-basis.md`。

## 执行

1. 把关键事实、假设、反证和失效条件转成逐项检查项。
2. 为每个未通过项指定补证据责任、复核日期和等待触发条件。
3. 区分“条件满足后行动”“条件不满足暂不行动”和“条件失效后停止”。

责任人、日期或证据门槛缺失时标为 `NEEDS_INPUT`，不得自行编造后继续执行。

## 输出

输出“检查项｜事实/推断/假设｜证据门槛｜责任人｜复核日期｜等待或停止条件”，并给出可执行的条件句。

## 边界

不把等待写成无期限拖延，不自动创建提醒、定时任务或后台监控，不替代前七个叶子的专业检查；关键证据缺失或安全边际不足时明确暂不行动。
