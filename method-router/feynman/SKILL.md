# 费曼技巧（Feynman Technique）

## 定位

以"教"为镜验"学"：把概念用最直白的话讲给门外汉听，讲的过程中
卡壳、绕圈、依赖术语的地方，就是理解漏洞。它把"我以为懂了"变成
"我能讲清楚"的可检验状态。

## 适用场景

- 学习完一个概念/算法/机制后的自检
- 面试前"能不能讲清楚"的演练
- 写科普、教徒弟、给团队解释架构
- 用户提到：我理解了吗、教教我、讲不明白、学习、复习、面试、简单解释、费曼

## 核心步骤

1. **选一个概念写在纸面上** — 一次只做一个，写不下就说明对象太大
2. **用大白话+类比讲给小白听** — 禁止术语堆砌；每引一个术语就要解释
   一次"用一句话怎么说"
3. **卡壳处回炉** — 讲不下去/逻辑断裂的地方回原资料补漏，补完重讲
4. **压缩成电梯版** — 2-3 句话讲清楚："它是……，因为它……，所以……"
5. **找人/复述验证** — 讲给真人听看反馈，或对着录音回放自检

## 示例

**概念**：二叉搜索树。
- 电车版：一种排序规矩的树——左小右大，查找时每次砍掉一半。
- 卡壳点："平衡"讲不清 → 回炉：不平衡会退化成链表，所以有旋转。
- 电梯版：BST 靠"左小右大"的规矩实现 O(log n) 查找；若插入顺序
  不好会退化，平衡树通过旋转维持高度，保证查询效率。

## 边界与互补

| 框架 | 关系 |
|------|------|
| SCQA | 讲清楚（电梯版）本身是 SCQA 的压缩形态；汇报前用费曼验证"是否真懂" |
| 知识库 | 学完概念 → 用费曼验证 → 再沉淀进知识库，避免存"半懂"内容 |

## 输出格式

```markdown
## 费曼验证：{概念}

- 原理解释（大白话）：...
- 类比：...
- 卡壳点：{处} → 已补：...
- 电梯版（≤3 句）：...
```

> **核心价值**：术语是理解的遮羞布——能用类比讲清，才算真的懂。
