# 激励机制分析

## 输入

提供参与者、决策权、报酬、约束、信息差和实际行为。需要时读取 `../references/munger-source-basis.md`。

## 执行

1. 为每个参与者列出目标、收益、损失、权责和信息优势。
2. 检查激励是否与期望行为一致，识别代理问题和可被利用的规则；只写成可观察的行为预测，不推断人格或内心动机。
3. 为行为预测给出基准行为、反事实解释和验证证据，再记录待验证假设与失效条件。

## 输出

输出“参与者｜激励｜权责｜信息差｜可观察行为预测｜基准/反事实｜验证证据｜失效条件”，并指出需要修改的约束。

## 边界

不对个人动机作无证据的人格判断，不把激励分析当作因果证明；关键行为无法验证时保留推断并谨慎行动。
