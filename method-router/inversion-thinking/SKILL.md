# 逆向思考

## 输入

提供当前目标、拟议行动、不可接受损失和可观察证据。需要时读取 `../references/munger-source-basis.md`。

## 执行

1. 假设行动已经失败，列出导致失败的独立路径。
2. 对每条路径写最坏后果、早期预警信号和可逆的预防约束。
3. 区分事实、推断和假设，为最关键的假设写反证与失效条件。

## 输出

输出“失败路径｜后果｜预警信号｜预防约束｜反证｜失效条件”，并给出是否应等待关键证据。

## 边界

本 Skill 只做开放式反向提问与约束提取：需要按概率×影响排序时转交 pre-mortem，需要顶事件、AND/OR 逻辑和最小割集时转交 FTA。它不替代概率预测、风险评级或完整决策；没有可观测信号时必须标注假设，最坏损失不可接受时允许暂不行动。
