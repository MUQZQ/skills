# 思维模型格栅

## 输入

提供决策问题、已选模型及其事实/推断/假设。需要时读取 `../references/munger-source-basis.md`。

## 执行

1. 为每个模型写出对同一事实的预测或解释。
2. 建立“模型 A｜模型 B｜关系｜共同假设｜证据缺口”的交叉矩阵，标记相互支持、冲突、不可比较和共同盲点。
3. 对冲突逐项寻找反证、补充数据和失效条件，不用多数模型投票代替判断；证据仍不能区分模型时停止收敛并保留 `unresolved`。

## 输出

输出“模型交叉矩阵｜冲突点｜共同盲点｜待验证假设｜失效条件”，并说明哪些结论仍不能确定。

## 边界

不负责替用户选择全部模型，不把模型数量当作可信度，不输出投资预测；无法消解冲突时保留不确定性或暂不行动。
