# 多元思维模型

## 输入

提供一个具体决策、可选行动、目标、时间窗口和已知证据。需要时读取 `../references/munger-source-basis.md`。

## 执行

1. 将材料分为事实、推断和假设，给事实标注来源。
2. 从概率、经济学、系统、工程、组织或行为等学科选择至少两个相关模型；只有能解释具体机制、证据可获得且与其他模型不重复时才纳入。
3. 对每个模型写出它解释什么、忽略什么、支持与反对当前行动的证据，并提出反证和失效条件。

## 输出

用表格输出“模型｜适用问题｜证据｜盲点｜反证｜失效条件”，最后给出仍需验证的假设。该叶子只完成模型选择与单模型检查。

## 边界

不把模型清单当作结论，不代替思维模型格栅的交叉比较，不预测投资收益；证据不足时明确暂不行动。
