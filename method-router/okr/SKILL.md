# OKR 目标与关键结果

## 定位

把"想达到什么"（O）与"怎么证明达到"（KR）绑定的阶段目标框架。
O 要激励人，KR 要可验证；定期评分产生数据，支持复盘与调整。
区别于 KPI（考核结果）：OKR 牵引前进的动作与方向。

## 适用场景

- 制定季度/月度目标（工作、学习、健康）
- 项目里程碑的量化与跟踪
- 目标长期"有想法没落地"，需要结构与节奏
- 用户提到：OKR、目标管理、关键结果、季度目标、里程碑、KR

## 核心步骤

1. **定 1-3 个 O** — 定性、有野心、方向性（"降持仓成本""掌握 DSA"）；
   每个 O 过 SMART 校验（至少 M 和 T）
2. **每 O 拆 3-5 个 KR** — 定量、可验证、有基线（"成本从 1.2% 降到 0.8%"）
3. **定周期与评分节奏** — 季度/月度 + 每周快检、月末评分
4. **定期评分 0-1** — 每个 KR 独立打分（0.7 以上=达成，0.3=有进展但偏离）
5. **周期末复盘** — 结合 KPT/双环学习复盘：KR 达标了吗？O 是否应该调整？
   产出下期 OKR

## 示例

- O1：本季度把主力标的持仓成本降低 0.5 个百分点
  - KR1：完成 3 次纪律性正 T 操作（记录决策链）
  - KR2：回撤＜2% 的天数占比 ≥80%
  - KR3：交易成本（佣金+滑点）合计 ≤0.3%
- O2：系统掌握二叉树类题目（进度 0.7 → 0.9 通过率）

## 边界与互补

| 框架 | 关系 |
|------|------|
| KPI | KPI 是被考核的结果指标，OKR 是牵引的动作目标；可并存但别混用 |
| SMART | 每个 O/KR 需过 SMART 校验（OKR 的 KR 天然要求可度量、有时限） |
| PDCA | OKR 周期本身即 P（定目标）+ D（执行）+ C（评分）+ A（复盘） |
| KPT/双环学习 | 周期末复盘输出，可衔接 KPT（轻）或双环学习（深） |

## 输出格式

```markdown
## OKR 周期 {周期}

- O1：{目标}
  - KR1：{指标} 基线 {x} → 目标 {y}（评分 {n}）
  - KR2：...

### 周期末复盘
- 达成率：{KR 达标数}/{总数}
- 偏差原因：...
- 下期调整：...
```

> **核心价值**：OKR 不考核人、只检验方向——评分低不是说"失败"，
> 而是说"方向没走对"，调整比惩罚重要。
