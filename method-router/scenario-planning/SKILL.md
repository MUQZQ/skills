# 情景规划（Scenario Planning）

## 定位

为不确定的未来准备 2-3 个"叙事剧本"：不同关键变量组合下世界长什么样，
我们的决策在不同剧本下分别是什么结果。不预测单一未来（赌），而是
确保"无论哪个剧本都大体可行"（抗打击）。

## 适用场景

- 决策影响期 6 个月以上，关键变量不可知（供应、政策、技术路线、市场）
- 重大投入前（新平台、新供应商、方向选择）
- 对单一预测不放心，需要"The plan for every world"
- 用户提到：未来、不确定、如果那怎么办、预案、情景、长远、多方面准备

## 核心步骤

1. **明确决策与时间跨度** — 现在要定什么、影响多久
2. **列关键不确定性变量** — 挑 2-3 个影响最大、最不可控的变量
3. **构建 2-3 个情景** — 变量组合成剧本（避免纯乐观/纯悲观，让每个
   剧本都可感知；可用"一个主要变量翻转"造差异化）
4. **每情景写故事** — 会怎样发展、先行信号（什么现象出现说明进入该
   剧本）、对这次决策的影响
5. **识别共同预案与专属预案** — 所有剧本都需要的动作（no-regret moves）
   先做；剧本专属动作用"信号触发"挂起
6. **输出行动表** — 现在做什么 + 什么信号触发转向

## 示例

**决策**：是否切换到某 AI 服务商（影响 12 个月）。
- 变量：服务稳定性 / 价格走势 / 竞争格局
- 剧本 A（基准）：稳定小幅涨价 → 维持现状 + 备用方案
- 剧本 B（高压）：限流涨价 → 触发信号：计费上调 30% → 切换预案
- 剧本 C（宽松）：竞品崛起降价 → 信号：对手价格 -40% → 重新议价
- 共同预案：接口抽象化（今日做）；专属预案：切换清单（挂起）

## 边界与互补

| 框架 | 关系 |
|------|------|
| FMEA/Pre-mortem | 针对已知失效模式（当下）；情景规划针对未知演化（未来） |
| 二阶思考 | 情景规划之后可用二阶思考深挖"若信号发生，我们动作的后果" |

## 输出格式

```markdown
## 情景规划：{决策}

| 情景 | 关键假设 | 发展故事 | 先行信号 | 对策 |
|------|---------|---------|---------|------|

**共同预案（现在做）**：...
**信号-动作表**：...
```

> **核心价值**：目标不是预测对未来，而是"任何剧本都留有后手"。
