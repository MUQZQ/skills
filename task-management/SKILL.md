# 任务管理域

## 职责

本 Skill 只负责识别任务管理意图并路由到域内叶子 Skill，不复制叶子的执行流程。权威映射位于
`references/task-mapping.yaml`。

## 路由规则

1. 用户显式指定子 Skill 时直接执行。
2. 每次只选择一个主 Skill；跨域生命周期交给 `orchestration`。
3. 从映射取得规范 `skill_name`，再通过根注册表解析 `<skill>/SKILL.md` 并严格执行其步骤。
4. 未匹配的任务管理需求返回缺口，不在本域临时扩展无权威定义的流程。

## 边界

- 滴答清单是唯一行动面板；日历与 Git issue 等外部数据源默认只读。
- 任务写入、删除、移动的授权闸门以叶子 Skill 为准；本域不越过叶子直接改数据。
- 方法论层面的时间管理、优先级分析走 `method-router`，本域只管具体任务数据的读写与对账。
